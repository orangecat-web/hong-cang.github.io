利用 GOOGLE Fonts 做出來的工具包。紅字部分自行更換

Include GOOGLE Font icon to SASS

@import url('https://fonts.googleapis.com/css?family=Material+Icons|Material+Icons+Outlined|Material+Icons+Two+Tone|Material+Icons+Round|Material+Icons+Sharp')

In SASS

// Material Icons Filled (base)

element.icon class

+google_icons(icon name)

// Material Icons Round

element.icon class

+google_icons(icon name, round)

// Material Icons outlined

element.icon class

+google_icons(icon name, outlined)

// Material Icons Sharp

element.icon class

+google_icons(icon name, Sharp)

// Material Icons Two Tone

element.icon class

+google_icons(icon name, Two Tone)

In HTML

< element class="icon class">

<span></span>

element.icon class

</element>
